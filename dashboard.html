🔌 Connect Visitor Analytics Database

1 Create a Free Supabase Database

Go to supabase.com, log in or create a free account, and set up a new project (e.g. jpgas-analytics). This takes less than 2 minutes.

2 Create the Database Table

Open the SQL Editor tab on the left sidebar in your Supabase project dashboard, click New Query, paste the following SQL script, and click Run: 

create table visits (
  id uuid default gen_random_uuid() primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  ip text,
  city text,
  region text,
  country text,
  user_agent text,
  referrer text,
  device text
);

-- Enable Row Level Security (RLS)
alter table visits enable row level security;

-- Create policy to allow public inserts
create policy "Allow public inserts" on visits 
  for insert with check (true);

-- Create policy to allow public selects (for dashboard loading)
create policy "Allow public selects" on visits 
  for select using (true);

3 Configure Your Website

Go to Project Settings -> API in Supabase, copy your Project URL and your anon/public API key, and paste them into your project's local config.js file: 

const CONFIG = {
  ADMIN_PASSCODE: 'jpgas2026',
  SUPABASE_URL: 'YOUR_SUPABASE_URL_HERE',
  SUPABASE_KEY: 'YOUR_SUPABASE_ANON_KEY_HERE',
  ...
};

Once saved and uploaded, your website will automatically log all incoming visits, and this dashboard will fetch and render live, real-time analytics!
